# 메모장 (가칭: AI 올인원 메모장)

메모, 할 일, 캘린더, 알림을 **한 앱에서** 쓰는 웹 앱입니다.
AX-Startup 부트캠프 학습용 프로젝트이며, 기획 문서는 [PRD.md](PRD.md), MVP 정리는 [MVP.md](MVP.md)에 있습니다.

- 배포 주소: https://ail-lecture-memo.vercel.app

## 기능

| 화면 | 기능 |
|---|---|
| 메모 | 작성·수정·삭제, 새로고침해도 유지 |
| 할 일 | 추가·완료 체크·삭제, 마감일, 중요도, 알림 시각 |
| 캘린더 | 월간 달력, 일정 추가(시간·알림), 마감일이 있는 할 일 자동 표시, 날짜별 모아 보기 |
| 알림 | 정해진 시각에 화면 안 알림(+허용 시 브라우저 알림), 닫아 둔 사이 지난 알림은 "놓친 알림"으로 안내, 켜기/끄기 |

> AI 요약 기능은 비용과 계정 확인 문제로 이번 버전에서 **뺐습니다.** 코드는 GitHub 커밋 `d77a760`에 남아 있습니다.

## 폴더 구조

```text
index.html        화면 뼈대 (메모 / 할 일 / 캘린더 탭)
style.css         모양
app.js            메모 기능
planner.js        할 일, 캘린더, 알림
MVP.md, mvp.html  MVP 정리 문서
```

## 내 컴퓨터에서 실행

터미널에서 아래 명령을 실행한 뒤 브라우저에서 http://localhost:4000 을 엽니다.

```bash
python3 -m http.server 4000
```

## 배포 (Vercel)

```bash
vercel deploy --prod
```

## 알아 둘 점

- 데이터(메모, 할 일, 일정)는 **사용하는 브라우저 안에만** 저장됩니다. 다른 기기에서는 보이지 않고, 외부로 전송되지 않습니다.
- 알림은 앱 화면을 열어 둔 동안만 울립니다.
- 주민등록번호, 계좌번호, 비밀번호 같은 민감한 정보는 적지 마세요.
