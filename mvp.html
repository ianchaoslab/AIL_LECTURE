1. 이번 결정: AI 기능은 뺀다 ✅

  • 기획자가 AI 기능(AI 요약, 메모에서 할 일 만들기)을 이번 MVP에서 제외하기로 했습니다.
  • 확인된 사실: AI 호출은 비용이 들고, 배포 환경의 Vercel AI Gateway가 계정 확인(customer_verification_required)을 요구해서 실제 요약 응답을 받아 보지 못했습니다.
  • AI 코드(ai.js, api/summarize.js, vercel.json)는 삭제했습니다. GitHub 이전 커밋(d77a760)에 남아 있어서 나중에 되살릴 수 있어요.

PRD.md는 고치지 않았습니다. PRD에는 M-2(AI 요약)와 T-3(메모에서 할 일 만들기)이 P0로 적혀 있어서, 이 문서의 범위와 PRD가 달라졌어요. PRD를 고칠지는 직접 정해 주세요.

2. MVP가 확인하려는 것 📝

"메모, 할 일, 일정, 알림을 앱 3개로 나눠 쓰는 것이 귀찮은 사람은, 한 앱에서 모두 쓸 수 있으면 쓸 것이다."

핵심 가치 (PRD 2-2)

  1. 메모, 할 일, 캘린더, 알림을 한 앱 안에서 끝낸다. 이번 MVP
  2. 정리되지 않은 메모를 AI 요약으로 바로 읽을 수 있게 만든다. 보류
  3. 메모 속 할 일과 일정을 다시 입력하지 않고 등록한다. 보류 (지금은 직접 입력)

3. MVP 범위와 현재 상태 ✅

진행률이번 MVP 범위 7개 모두 완료 · 보류 2개(AI 기능)

T-3메모에서 할 일 만들기5단계보류 (AI 요약에 의존)

알림 기능 요약 ✅

  • 할 일은 알림 시각을, 일정은 "정각·10분 전·1시간 전"을 고를 수 있어요.
  • 15초마다 확인해서 화면 안 알림을 띄우고, 브라우저 알림을 허용하면 그것도 띄웁니다.
  • 앱을 닫아 둔 사이 지난 알림은 다시 열 때 "놓친 알림"으로 알려 줘요.
  • 헤더의 🔔 스위치로 켜고 끕니다.

MVP에 넣지 않는 것 ✅

  • AI 요약, 메모에서 할 일 만들기, AI 할 일 정리, AI 채팅, 메모 기반 질문
  • 공유 기능, 휴대폰 앱, 외부 서비스 연동, 첨부 메모
  • 메모 검색, 태그, 메모 고정, 날짜별 모아 보기(메모 포함), 이메일·푸시 알림

4. 핵심 사용 흐름 📝

  1. 메모를 적고 저장한다.
  2. 할 일 탭에서 할 일을 추가하고 마감일·알림 시각을 정한다. (직접 입력)
  3. 캘린더에 마감일과 일정이 표시된다.
  4. 정해진 시각에 앱 안에서 알림이 뜬다.

5. 지금 알려진 한계 ✅

  • 저장은 브라우저 안에서만 됩니다. 다른 기기·다른 브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 사라집니다. (PRD 7-3)
  • 알림은 앱 화면을 열어 둔 동안만 울립니다. 닫아 둔 사이의 알림은 다시 열 때 알려 줘요. (PRD 4-4)
  • 로그인이 없어서 사용자 구분이 없습니다.
  • 메모에서 할 일과 일정을 자동으로 옮기는 기능이 없어서, "다시 입력하지 않고 등록"하는 가치는 이번 MVP에서 확인할 수 없습니다.

6. MVP 검증 방법 📝

PRD 10장 원칙대로 목표 숫자는 첫 테스트 뒤에 정하고, 측정할 항목만 적습니다. AI 요약 관련 항목은 뺐어요.

측정 항목확인하려는 것
알림을 설정한 할 일·일정의 비율알림 기능을 쓰는가
알림 설정 후 실제로 확인한 비율알림이 제 역할을 하는가
메모·할 일·캘린더 중 많이 쓰는 화면어떤 기능이 핵심인가
테스트 사용자 한 줄 소감: "앱을 따로 열지 않아도 되는가?"핵심 가설이 맞는가

⚠️ 위 측정 항목 중 일부는 사용 기록을 모으는 기능이 아직 없어서 지금은 숫자를 볼 수 없어요. 처음에는 사용자에게 직접 물어보는 방식으로 시작해도 됩니다.

7. 위험 요소 📝

위험대응
AI 없이는 "정리해 주는 앱"이라는 차별점이 약하다나중에 AI를 다시 넣을지 결정 (코드는 GitHub 이전 커밋에 있음)
앱을 닫으면 알림을 못 받는다한계를 화면에 안내, 필요하면 푸시 알림 단계 추가
데이터가 브라우저에만 있어 잃어버린다한계를 문서에 안내, 이후 서버 저장으로 확장
메모에 민감한 개인정보가 들어간다입력 안내 문구(적용됨). 지금은 외부로 전송되지 않고 브라우저에만 저장됨

8. 직접 결정해야 하는 것

  1. PRD를 고칠까요? M-2, T-3을 P0에서 빼거나 "보류"로 바꾸는 것을 포함해서요.
  2. MVP의 목적은? 포트폴리오 시연용인지, 실제 사용자 테스트용인지
  3. AI를 나중에 다시 넣을 계획이 있는가? 있다면 비용 부담과 이용 방식을 먼저 정해야 해요.
  4. 알림은 컴퓨터 화면이면 충분한가? 앱을 닫은 채 휴대폰으로 받아야 한다면 푸시 알림 단계가 필요합니다.
  5. 앱 이름은? (지금 "AI 올인원 메모장"은 PRD의 가칭이에요. AI를 뺐으니 바꾸는 것을 고려해 보세요.)
